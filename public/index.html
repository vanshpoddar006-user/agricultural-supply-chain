Project Architecture & Academic Documentation

Complete technical overview of Java + Applet/Swing + MySQL Database Connectivity.

🗄️ MySQL Database Connectivity

The system contains a production-ready SQL script in database.sql:

-- Quick MySQL setup
CREATE DATABASE agri_supply_chain;
USE agri_supply_chain;
SOURCE database.sql;

Tables included: farmers, crops, batches, logistics, retail_orders.

☕ Java + Applet / Swing Implementation

Your workspace includes full standalone Java source files:

  • DBConnection.java: Handles JDBC connection via com.mysql.cj.jdbc.Driver.
  • AgriSupplyChainApp.java: Dual-mode application (extends JApplet for legacy applet submission & includes main() for modern desktop execution).
# Compile Java Application:
javac -cp ".;mysql-connector-j.jar" *.java

# Run Desktop / Applet Window:
java -cp ".;mysql-connector-j.jar" AgriSupplyChainApp

🌐 Why Modern Web + Java Dual Architecture?

Modern web browsers (Chrome, Edge, Firefox) deprecated and removed Java Applet NPAPI plugins. By providing both:

  • ✅ Modern Website: Instantly interactable in any modern browser on PC, tablet, or phone.
  • ✅ Java + Applet Source: Fully satisfies syllabus requirements for university or college presentations.
